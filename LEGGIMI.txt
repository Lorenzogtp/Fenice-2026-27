Questa cartella contiene la versione installabile e aggiornabile del file HTML fornito.

PUBBLICAZIONE SU GITHUB PAGES
1. Aprire il repository GitHub usato per l'app.
2. Caricare nella radice TUTTI i file di questa cartella, sostituendo quelli omonimi.
3. Fare Commit changes.
4. Verificare Settings > Pages: Deploy from a branch, branch main, /(root).
5. Aprire il link GitHub Pages e premere ↻ Aggiorna nell'app.

FILE PRINCIPALI
- index.html: applicazione completa
- manifest.webmanifest: installazione PWA
- sw.js: cache offline e aggiornamenti
- icon-192.png / icon-512.png: icone
- .nojekyll: compatibilità GitHub Pages
